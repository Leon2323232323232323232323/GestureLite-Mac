# Required Mac acceptance tests — not yet executed

Record hardware, macOS version, CPU architecture, keyboard layout, mouse/driver and app hash. Test both Apple Silicon and Intel before claiming both are supported. Core tests or CI compilation do not prove these behaviors.

1. Build with `bash scripts/build.sh`. Verify tests, both architecture compiles, lipo, ad-hoc codesign validation, native bridge self-test and checksum output pass. Inspect linked libraries for build-machine dependencies. No paid identity, secrets or notarization should be used.
2. On a clean user account, download via a browser and install the ZIP as a normal user. Verify the actual Gatekeeper warning and app-specific approval flow. Do not alter global protections. Test a fresh download; running a locally built app alone does not test quarantine behavior. Test approval after updating the ad-hoc build as well.
3. Deny permissions and try enabling: app must stay disabled, display a useful error and pass normal input. Grant requested permissions and enable deliberately. Revoke permission while active and verify safe failure/recovery. The app must start disabled on every launch.
4. With a US keyboard layout and a plain text editor, assign CMD+A to a click action. Press and hold still: no output until release. Release: one selection action. Repeated down events must not repeat it. Set No action and confirm the normal-tap checkbox controls fallback. Clear every temporary mapping when finished.
5. In a disposable browser tab with history, test raw Mouse4/5 normal taps. One physical click must yield one replay; no repeated navigation, new gesture arming, key holding or input flood. Repeat click/release then hold/swipe at least 50 times, varying speed and direction. Verify normal typing and scrolling throughout.
6. Hold a trigger and move less than 360 points: no gesture. Cross the threshold horizontally/vertically: one correct shortcut before release. Further movement in the same hold, even reversing, must not repeat. Release, then move without pressing: nothing. Unmapped directions consume the click, matching the documented preview behavior. Test diagonal dominance and changed distance.
7. Configure a custom click and a gesture on the same trigger. A completed gesture must suppress the click and the normal button action. No completed gesture must run only the click on release. Repeated quick taps must not pause other gestures.
8. Hold real Command/Control/Option/Shift keys during output; the app must not release keys the user is holding, or leave a synthetic modifier down afterward. Hold the target key and verify it is not spuriously released by a shortcut. Test F13–F20 passthrough and click actions; driver-generated key pairs must remain accepted while own generated events are ignored.
9. Disable gestures, apply new settings, close the app, sleep/wake and change sessions during a held trigger. No delayed click or gesture should fire. After a tap-disable notification, status must be off with no automatic half-hold resumption. Release physical triggers before enabling again.
10. Verify all Settings fields, scroll visibility, presets, custom shortcuts, Add/Remove, invalid values and duplicate trigger rejection. Change JSON externally before Save: external file must be preserved. Relaunch with malformed JSON: original file must remain and gestures must not enable automatically. Check JSON backups and log rotation.
11. Test multiple monitors, Retina scaling and screen edges. Distance is screen-coordinate points and cursor displacement, not raw HID travel; a pointer pinned to an edge cannot accumulate further distance. Test layout changes while held. Use one trigger at a time; simultaneous-hold limitations are documented.
12. Test desktop shortcuts with at least three Spaces and enabled Mission Control shortcuts. Only one switch per hold; no switch when already at a boundary. Distinguish an earlier WindowServer animation finishing after release from a new action. Do not infer successful input delivery only from CGEvent.post returning.
13. Measure idle CPU, working memory and installed/ZIP size on the actual Mac with Settings both open and closed. Confirm no polling timer or network activity and no process remaining after Quit. No performance figures are claimed yet.
14. Uninstall and verify per-user settings retention and documented permission cleanup. Ensure no launch agent, system extension, driver, paid certificate, security-policy change or auto-updater exists.

Any unexplained lost input, recursive clicks or stuck keys is a release blocker. Keep gestures disabled until diagnosed. Do not add timing, repeats or hook-recovery heuristics to conceal a failure.
